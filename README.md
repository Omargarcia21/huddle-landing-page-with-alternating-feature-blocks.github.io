# Solución al Desafío de Frontend Mentor: Landing Page de Huddle con Bloques de Características Alternas

![Badge](https://img.shields.io/badge/Estado-Completado-brightgreen)  
Este es mi solución al desafío **Huddle Landing Page with Alternating Feature Blocks** de Frontend Mentor. El objetivo era crear una landing page estática y responsiva utilizando **HTML** y **SASS**, con un enfoque en aprender la maquetación y los estilos con un preprocesador CSS.

**Desafío de Frontend Mentor:** [Huddle Landing Page](https://www.frontendmentor.io/challenges/huddle-landing-page-with-alternating-feature-blocks-5ca5f5981e82137ec91a5100)  
**Live Demo:** [Ver Proyecto en Vivo](https://omargarcia21.github.io/huddle-landing-page-with-alternating-feature-blocks.github.io/)

## Descripción del Proyecto

Este proyecto es una landing page estática que presenta información sobre un servicio ficticio llamado **Huddle**. La página incluye:

- Un **header** con un diseño atractivo y un botón de llamada a la acción.
- Varias **secciones de características** que alternan entre imágenes y texto para describir los beneficios del servicio.
- Un **footer** con enlaces útiles y redes sociales.

El diseño es completamente responsivo, utilizando **SASS** para organizar y modularizar los estilos, lo que facilita el mantenimiento y la escalabilidad del código.

## Tecnologías Utilizadas

- **Lenguajes de Programación**: HTML, SASS (CSS preprocesado).
- **Metodologías CSS**: Flexbox y Grid para la disposición de los elementos.
- **Diseño Responsivo**: Compatible con dispositivos móviles, tablets y desktop.
- **Preprocesador CSS**: SASS para una gestión más eficiente de los estilos.

## Instrucciones de Instalación y Uso

Este proyecto es una página web estática, por lo que no requiere instalación.
